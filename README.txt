APLIKASI VOUCHER POS

INSTALASI:
1. Copy folder aplikasi_voucher ke C:\xampp\htdocs\
2. Jalankan Apache dan MySQL dari XAMPP.
3. Buka http://localhost/phpmyadmin
4. Import file database.sql.
5. Buka http://localhost/aplikasi_voucher/

MOBILE:
- Pastikan HP dan komputer XAMPP berada pada WiFi/LAN yang sama.
- Cari IP komputer dengan perintah: ipconfig
- Dari HP buka: http://IP-KOMPUTER/aplikasi_voucher/
  Contoh: http://192.168.1.10/aplikasi_voucher/

BARCODE SCANNER:
Scanner USB/Bluetooth yang bekerja sebagai HID Keyboard akan langsung kompatibel.
Atur scanner agar mengirim ENTER setelah barcode.
